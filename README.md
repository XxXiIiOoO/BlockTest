# BlockTest

**BlockTest** — веб-платформа для автоматизации тестирования блокчейн-приложений и смарт-контрактов.

Идея проекта — объединить процесс тестирования в одном месте: от создания проекта и запуска тестов до просмотра результатов и анализа ошибок.

Вместо ручного запуска проверок через консоль пользователь может управлять тестированием через веб-интерфейс, отслеживать историю запусков и получать статистику по выполненным тестам.

## ⚙️ Возможности

- Создание проектов и управление тестами.
- Запуск проверок смарт-контрактов с помощью Hardhat.
- Выполнение тестов в изолированных Docker-контейнерах.
- Фоновое выполнение тестов и просмотр логов.
- Просмотр результатов, истории запусков и статистики.
- Экспорт отчётов в JSON, HTML и PDF.
- Авторизация и разграничение прав доступа.

## 🛠️ Технологии

| Компонент | Стек |
|---|---|
| Backend | Python, FastAPI, SQLAlchemy, Alembic |
| Frontend | React, TypeScript, Vite |
| База данных | PostgreSQL |
| Фоновые задачи | Redis, TaskIQ |
| Blockchain | Hardhat |
| Инфраструктура | Docker Compose |

## 🔧 Как это устроено

В основе BlockTest — взаимодействие нескольких компонентов: веб-приложения, API, очереди фоновых задач и среды тестирования смарт-контрактов.

Каждый из них отвечает за свою часть процесса, формируя единую систему для автоматизации тестирования.
